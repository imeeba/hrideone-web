## 1. โปรเจกต์คืออะไร

รื้อ [hrideone.com](https://hrideone.com) (HRI DeOne — สถาบันฝึกอบรมผู้บริหาร) จาก WordPress + Elementor
มาเป็น WordPress Block Theme ที่เบา ใช้ปลั๊กอินน้อยที่สุด โค้ดเฉพาะของเว็บอยู่ใน repo นี้

- เจ้าของงาน: Jimmi (คุยภาษาไทย ตอบเป็นภาษาไทย)
- คนแก้เนื้อหาหลังส่งมอบ: ทีมการตลาด → ทุกอย่างต้องแก้ได้จาก editor โดยไม่ต้องเขียนโค้ด
- โฮสต์ปลายทาง: Ruk-com Managed WordPress (มี Rcache = NGINX proxy cache, shared hosting ไม่มี SSH/Git/Composer)
- **ห้ามแตะ Production** ทำงานบน Playground / local / staging เท่านั้น
- ไม่มีงบปลั๊กอินเสียเงิน ถ้าอะไรต้องเสียเงินให้ถาม Jimmi ก่อน

## 9. วิธีทำงานที่ประหยัด usage

- **เริ่มแชท**: "ทำเว็บ hrideone ต่อ repo imeeba/hrideone-web อ่าน docs/HANDOFF.md แล้วทำ <งาน>" + prompt จาก [`PROMPTS.md`](PROMPTS.md) · หนึ่งแชทต่อหนึ่งงานใหญ่
- **อ่านเท่าที่จำเป็น**: ไฟล์นี้ + `PITFALLS.md` ทั้งไฟล์ · ไฟล์อื่นเปิดเฉพาะหัวข้อที่เกี่ยว (`grep -n` หาก่อน) ไม่ต้องอ่าน `ARCHITECTURE.md` / `history/` ทั้งไฟล์
- **ใช้ Sonnet**: งานที่ prompt ระบุชัด + มีเกณฑ์ตรวจเป็นตัวเลข ทำได้ใกล้เคียง Opus · งานที่ต้องใช้วิจารณญาณ (จัดหมวด/เขียนเนื้อหา) หรือเจอพฤติกรรมแปลกของ WordPress/Polylang มีโอกาสหยุดที่ "ดูเหมือนใช้ได้" → prompt จึงใส่ **เกณฑ์ผ่าน** ทุกข้อ ห้ามข้าม · แก้ปัญหาเดิม 2 รอบไม่ผ่าน = หยุดแล้วรายงาน อย่าวนต่อ
- ตรวจด้วย JS/สคริปต์วัดค่า (ขนาด/overflow/การแสดงผล) ก่อน ใช้ screenshot เท่าที่จำเป็น
- **ปิดงาน — อัปเดตเอกสารให้ถูกที่** แล้ว push:
  - [`history/DONE-LOG.md`](history/DONE-LOG.md): เพิ่มรอบใหม่ไว้บนสุดของข้อ 5 (ทำอะไร, branch, จุดย้อนกลับ, ผลทดสอบ)
  - [`ARCHITECTURE.md`](ARCHITECTURE.md): ถ้าโครงสร้าง/ไฟล์/ฟีเจอร์เปลี่ยน · [`PITFALLS.md`](PITFALLS.md): ถ้าเจอกับดักใหม่ · [`OPEN-QUESTIONS.md`](OPEN-QUESTIONS.md): ถ้ามีข้อมูลสมมติ/เรื่องรอตัดสินใจใหม่ · [`BACKLOG.md`](BACKLOG.md): ขีดฆ่างานที่เสร็จ
  - [`quality/STANDARDS.md`](quality/STANDARDS.md) ข้อ 3: อัปเดตผลวัดล่าสุด (วันที่ + ค่า) ของด้านที่งานนั้นแตะ
  - ไฟล์นี้: แก้แค่ข้อ 0 (สถานะ) และบรรทัด "อัปเดตล่าสุด" — **ห้ามย้ายรายละเอียดกลับมาที่นี่**
  - README ถ้าโครงสร้างเปลี่ยน · bump `Version` theme/plugin ตามที่ prompt บอก
- Commit message ปิดท้ายด้วยบรรทัด attribution ตามที่ระบบกำหนด

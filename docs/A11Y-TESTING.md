# A11Y-TESTING — ทดสอบการเข้าถึง (WCAG 2.2 AA)

เป้าหมาย: WCAG 2.2 ระดับ AA ทั้งเว็บ (Jimmi ตกลง 8 พ.ย. 2569) · หน้าประกาศ: `/accessibility/` (TH/EN/JA)

## 1. อัตโนมัติ (ทุก PR ใน GitHub Actions → workflow **CI**)

| สคริปต์ | ตรวจอะไร |
|---|---|
| `scripts/a11y-check.mjs` | axe-core WCAG 2.0–2.2 A/AA + best practice, 9 หน้า × 1280/375 px |
| `scripts/keyboard-check.mjs` | Tab ทุกจุด: เห็น focus ไหม (2.4.7), โดน header บังไหม (2.4.11), skip link เป็นจุดแรก, เมนูมือถือเปิด/ปิดด้วย Enter/Esc และ focus กลับ, reflow 320 px (= ซูม 400%, 1.4.10) + text spacing (1.4.12) |
| `scripts/measure.py` | overflow, tap target 44 px, contrast, PHP error, JS error |
| Lighthouse (`lighthouserc.json`) | คะแนน accessibility ≥ 95, best practices / SEO ≥ 90 |

รันเองบนเครื่อง: `scripts/local-setup.sh` แล้ว `npm i --no-save playwright axe-core && node scripts/a11y-check.mjs && node scripts/keyboard-check.mjs`

เครื่องมืออัตโนมัติจับปัญหาได้ราวหนึ่งในสาม ที่เหลือต้องคนทดสอบ (ข้อ 2)

## 2. Screen reader บนมือถือ (คนในทีม ~30 นาที, ทำก่อน go-live และทุกครั้งที่เปลี่ยน layout ใหญ่)

**เปิด**: iPhone → ตั้งค่า → การช่วยการเข้าถึง → VoiceOver (หรือสั่ง Siri "เปิด VoiceOver") · Android → ตั้งค่า → การช่วยเหลือพิเศษ → TalkBack
**ใช้**: ปัดขวา = ไปถัดไป · ปัดซ้าย = ย้อน · แตะสองครั้ง = กด · (iPhone) หมุนสองนิ้ว → "หัวเรื่อง" แล้วปัดลง = กระโดดทีละหัวข้อ

เปิด `https://new.hrideone.com/` แล้วทำทีละข้อ จดผลเป็น ✅ / ❌ + หน้าไหน + ได้ยินอะไร

1. [ ] หน้าแรก: ได้ยินชื่อหน้าและภาษาไทยออกเสียงถูก (ไม่อ่านเป็นภาษาอังกฤษสะกดทีละตัว)
2. [ ] ปัดผ่านเมนู: ได้ยิน "ปุ่ม เปิดเมนู" → แตะสองครั้ง → เมนูเปิด, ได้ยินชื่อเมนูทุกข้อ, ปิดได้
3. [ ] กระโดดทีละหัวข้อ (heading) ในหน้าแรก: ลำดับหัวข้อฟังแล้วเข้าใจโครงหน้า
4. [ ] รูป: รูปที่มีความหมายมีคำอธิบาย, รูปตกแต่งถูกข้าม (ไม่ได้ยินชื่อไฟล์ เช่น "IMG_1234")
5. [ ] ปุ่มสไลด์รูป (gallery): ได้ยิน "ก่อนหน้า / ถัดไป" และเลื่อนได้
6. [ ] หน้าหลักสูตรทั้งหมด: เลือกตัวกรอง 1 อัน → ได้ยินจำนวนผลลัพธ์ใหม่ ("พบ ... หลักสูตร")
7. [ ] หน้าหลักสูตร 1 หน้า: ได้ยินวันที่/รุ่น/สถานะ และปุ่มสมัครชัดเจน
8. [ ] ฟอร์มติดต่อ: ทุกช่องได้ยินชื่อช่อง + "จำเป็น", กดส่งโดยไม่กรอก → ได้ยินข้อความ error และรู้ว่าช่องไหนผิด
9. [ ] ส่งฟอร์มสำเร็จ: ได้ยินข้อความยืนยัน
10. [ ] สลับภาษาเป็น EN และ JA: ได้ยินภาษาเปลี่ยนตาม (เสียงอ่านเปลี่ยนภาษา)
11. [ ] ขยายตัวอักษรในเครื่องให้ใหญ่สุด แล้วเปิดเว็บ: ตัวหนังสือไม่ล้น ไม่ทับกัน
12. [ ] หมุนจอแนวนอน: ใช้งานได้ปกติ
